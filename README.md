# custom-tmr-imagery-maker

悪夢の筋書きを本人が望む場面へ書き換えるとき、「良いイメージを作る」と言われても、具体的な景色や動きを思い浮かべるのは簡単ではありません。`custom-tmr-imagery-maker` は、ChatGPT WorkやCodexなどのAIエージェントに一問ずつの聞き取りをさせ、練習に使う場面の**文章**と、希望に応じた**場面画像**づくりを助けるスキルです。研究・授業用の試作（v0.1.7）です。

## 研究の背景と、このスキルの役割

悪夢に対するイメージリハーサル療法（IRT）では、つらい夢の筋書きを本人にとって苦痛の少ない展開に書き換え、起きている間にその場面をイメージします。一般的な説明には1日5〜10分の練習があり、[Schwartzほかの研究（2022）](https://doi.org/10.1016/j.cub.2022.09.032)では、書き換えた場面を1日5分、2週間練習しました。標的記憶再活性化（TMR）は、覚醒中に音と結びつけた内容を睡眠中に音で再提示する研究手法です。この研究のTMR群では、初回のイメージ練習中に音を結びつけ、REM睡眠中にもその音を提示しています。

このリポジトリが扱うのは、その手前の**「どんな場面をイメージするか」を具体化する作業**です。AIが本人に一問ずつ尋ね、本人の選択を反映した文章を作ります。画像生成機能を使える環境なら、確認した文章から場面画像を一枚ずつ作ることもできます。文章や画像は練習を考えるための素材であり、画像の追加で効果が高まることや、このスキルで悪夢が改善することは検証していません。研究手順を自己治療として再現するものでもありません。詳しくは[研究との対応](skills/custom-tmr-imagery-maker/references/evidence.md)を参照してください。

## 何ができるか

1. 夢の中で何が起こり、どこが嫌なのかを一問ずつ整理する。
2. 本人が望む変化と、その先の景色・行動を具体化し、場面の文章にする。
3. 本人の希望があれば、文章を場面ごとに分ける。画像生成機能が利用できる場合は、画像を一枚ずつ作って確認する。利用できない場合は画像用の説明文を渡す。
4. 明示的に頼まれた場合だけ、文章や画像を指定場所へ保存する。WordやPDFへの書き出しは、利用環境の機能に依存する。

[試用例「ベッドから道へ」](examples/bed-to-street/README.md)には、対話で決めた場面の文章とAI生成画像3枚を掲載しています。[架空の対話例](demo/架空の対話例.md)では一問ずつの進め方を確認できます。

このスキル自体は、音と記憶の結びつきを測定・成立させたり、REM睡眠を検知したり、睡眠中に音を再生したりしません。5分間のタイマーや治療プログラムも実装していません。

## Codexで使う

GitHubにこのファイル群が公開された後、Codexで `$skill-installer` に「`hs-hg-2026/custom-tmr-imagery-maker` の `skills/custom-tmr-imagery-maker` をインストールしてください」と依頼できます。[OpenAIのスキル文書](https://learn.chatgpt.com/docs/build-skills)は、ほかのリポジトリからのインストールにも対応すると説明しています。

手動で置く場合は、ダウンロードした `skills/custom-tmr-imagery-maker` フォルダ全体を、Windowsでは `%USERPROFILE%\.agents\skills\custom-tmr-imagery-maker` にコピーします。`SKILL.md` だけでなく `references/` も一緒に残してください。Codexに表示されない場合は再起動します。

導入後の開始例：

> `$custom-tmr-imagery-maker` で、架空の悪夢から一問ずつ場面を作りたいです。

文章が本人のイメージに近くなった後の依頼例：

> この場面を3枚の画像にしたいです。1枚ずつ見せて、私の確認を待ってください。

## インストールせずに試す場合

Codexでこのフォルダを開き、`skills/custom-tmr-imagery-maker/SKILL.md` と必要に応じて `references/evidence.md` を読ませて、架空の題材で実演するよう依頼できます。これは**その作業中にファイルを参照する方法**で、スキルのインストールではありません。単にGitHubのURLやフォルダ名を会話に貼るだけで、自動的にスキルとして登録されるわけではありません。

ChatGPT Workなどで継続して使える形にするには、対応するプラグインの配布・導入手順が別途必要です。このリポジトリにはCodex互換の `.codex-plugin/plugin.json` を含みますが、GitHubに置くだけでChatGPT Workのプラグイン一覧に現れるわけではありません。[OpenAIのプラグイン文書](https://developers.openai.com/plugins/build/plugins)を参照してください。

## 安全とプライバシー

実体験を詳しく語る必要はなく、途中でやめられます。苦痛が強くなる場合は作業を止め、生活への支障が続く場合は専門家への相談も選択肢です。個人の体験や会話は、明示的な依頼なしに保存・公開しない指示にしています。利用サービス側のデータの取り扱いは別途確認してください。

この試作品の対話品質、画像を使う効果、音との学習、悪夢や睡眠への効果は未検証です。掲載した試用例も効果測定ではありません。
