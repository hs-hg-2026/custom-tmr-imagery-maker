- ベッドから歩いて引き戸を開けると、靴が並ぶ玄関が見える。靴を履き、玄関のドアから外へ出る。
- 外は春の木漏れ日のような穏やかな晴天。暑すぎず、湿気の少ないさらりとした風が吹く。
